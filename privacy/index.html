Политика конфиденциальности

Flight Assistant · обновлено 1 октября 2026 года

Flight Assistant обрабатывает только данные, необходимые для выполнения поиска авиарейсов и выдачи результата пользователю.

Какие данные обрабатываются

  • Параметры поиска: маршрут, даты, пассажиры, класс обслуживания и выбранные условия тарифа.
  • Технический идентификатор Telegram-чата используется для изоляции пользовательского состояния; он не публикуется в названии временной таблицы.
  • Результаты поиска, полученные от авиационного провайдера.

Использование Google Drive

OAuth-доступ Google Drive предоставляется только владельцем Flight Assistant к собственному Google-аккаунту сервиса.

Доступ используется для копирования шаблона, заполнения, предоставления ссылки только для просмотра и последующего удаления временных таблиц с результатами поиска.

Flight Assistant не запрашивает OAuth-доступ к Google-аккаунтам публичных пользователей и не читает их Google Drive.

Хранение и передача

Временная таблица создаётся только после успешного поиска и предназначена для кратковременной выдачи результата. Плановый срок доступности — 30 минут после последнего успешного обновления, после чего сервис удаляет свою временную копию.

Данные Google-аккаунта владельца не продаются и не используются для рекламы. Доступ к Google API применяется только для описанной функции временных таблиц.

Параметры авиапоиска передаются авиационному провайдеру только для выполнения поиска. Flight Assistant не выполняет бронирование и оплату.

Безопасность

OAuth-секреты и токены хранятся вне публичного репозитория в защищённом credential store сервиса.
